PhoneController

Turn your Android phone into a wireless Xbox 360 controller for Windows — over local Wi-Fi.

View Source Download Privacy Policy

Real XInput Gamepad

Games see an actual "Xbox 360 Controller for Windows" via ViGEmBus — not keyboard emulation.

Floating Joysticks

Stick bases appear wherever your thumbs land. Both sticks work simultaneously.

Auto-Discovery

The app finds your PC automatically on the same Wi-Fi. No IP addresses needed.

Full Button Set

A, B, X, Y, LB, RB, LT, RT, Start, Select — plus remapping to keys or mouse.

No Data Collected

No accounts, no analytics, no ads. Input stays on your own network.

2-Minute Setup

Install ViGEmBus, run the Python server, tap your PC in the app. Done.
